# BlueLine Plumbing

A fast, mobile-friendly landing page concept for a home services business, designed to turn visitors into phone calls.

**Live demo:** https://mattsunny-dev.github.io/plumbing-concept/

## Features
- Click-to-call buttons
- Sticky Call Now and Free Quote bar on mobile
- Free quote form with service selection (demo only, nothing is sent)
- Services section, how it works steps and sample reviews
- Responsive layout for phones, tablets and desktops

## Built with
HTML, CSS and JavaScript. Hosted on GitHub Pages.

## Note
This is a concept project with sample content. It can be customized with a business's name, services, service area, photos and phone number.
